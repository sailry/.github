<h1 align="center">Sailry</h1>

<p align="center">把 AI 智能体、文件和工具放在同一个原生工作区</p>

<p align="center"><a href="https://github.com/sailry">English</a></p>

<p align="center">
  <img src="https://raw.githubusercontent.com/sailry/sailry-harness/main/assets/readme/workspace-dark.png" alt="Sailry 暗色模式工作区" width="860" />
</p>

使用自己的模型，在对话旁处理文件、Git、终端、浏览器、SSH 和数据库。任务可在本机或自己的服务器上运行。

| 仓库 | |
| --- | --- |
| [sailry-harness](https://github.com/sailry/sailry-harness) | 应用、Node 运行时和插件 SDK |
| [sailry-plugins](https://github.com/sailry/sailry-plugins) | 官方插件包与 SDK 示例 |
| [sailry-themes](https://github.com/sailry/sailry-themes) | 官方主题包 |

[下载 macOS 版](https://github.com/sailry/sailry-harness/releases?q=prerelease%3Afalse)（macOS 13+，Apple 芯片与 Intel）。Windows 和 Linux 计划中。
